# 对象实例建模示例

[ops-demo-topology.json](examples/ops-demo-topology.json) 是可从“事实接入 → 对象实例建模 → 导入拓扑”直接选择的 UTF-8 JSON 文件。

按 2026-10-15 当前工作空间的运维对象模型构造，共 **18 个实例、22 条关系**：应用、服务、服务实例、主机、告警、工单各 3 个，包含支付、清结算和通知三条链路，工单可关联多个服务。来源标识为 `DEMO-OPS-20261015`，业务编码统一使用 `DEMO-` / `demo-` 前缀，人员、指标和地址均为合成示例。

可测试画布缩放、全屏与 Esc 退出、横向和纵向布局、搜索与类型筛选、邻域聚焦、抽屉查看与编辑、枚举值、整数端口、小数 SLA、日期和带 `NOT_APPLICABLE` 原因的空值。工单的“关联服务”关系适合测试新增、解除关系以及删除保护；编辑后可在操作记录中查看留痕。

文件中的所有关系通过 `instanceKey` 在文件内闭合引用，实例稳定标识由后端生成。重复导入同一文件会因业务标识重复整批拒绝，已有数据不会被覆盖；对象模型属性、枚举或关系约束变化后，应先同步修改示例文件再导入。
