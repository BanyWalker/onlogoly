# 本体模型产物目录

`ontology/` 保存模型定义及相关样例。当前 SRS-OM-001 v1.6.0 的模型类型为**对象模型、规则模型**；术语由独立术语管理模块维护，模型通过稳定标识引用释义。公共建模能力不作为模型类型。

## 组织方式

目录表示产物位置预留，格式和模型包版本治理待相应需求、TDD/ADR 批准后确定：

```text
model-packages/<package>/
├─ manifest.<format>      # 包格式及版本治理待确定
├─ objects/               # 本期对象模型
├─ rules/                 # 本期规则模型
├─ behaviors/             # 后续行为需求预留
├─ fixtures/              # 与定义分离的合成样例
└─ expected/              # 案例预期及复核材料
```

`model-packages/ops/` 表示合成运维案例，不代表平台内置本体。当前字段要求统一见 [SRS-OM-001 §8](../../曦元本体平台SDD开发/01_需求规格/本体建模/01_本体建模需求规格说明书.md#8-数据字典与生命周期)。

元素修订、历史查询和引用检查按当前 SRS 定义；包版本、平台内审批、导入导出、审计及恢复由后续治理需求承接。目录预留不要求首期实现这些功能，源文件与交换格式待设计确定后采用单一权威来源。
