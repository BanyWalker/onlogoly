# 曦元本体平台产品实现目录

本目录存放实际产品实现、定义相关资源、数据库脚本、测试和部署配置。项目规格、设计、任务、验证证据和发布记录仍存放在上级的 `曦元本体平台SDD开发/`，不在本目录复制一份。

## 目录职责

| 目录 | 内容 |
| --- | --- |
| `apps/` | 面向用户的应用，例如本体建模工作台前端 |
| `services/` | 后端 API 和应用服务 |
| `services/workspace-data/` | 与后端代码平级的本地 JSON 数据目录，真实数据与备份不纳入 Git |
| `packages/` | 可复用的模型结构、校验和公共代码 |
| `terminology/` | 独立术语管理与术语资料，按稳定标识供模型引用 |
| `ontology/` | 本期对象/规则定义相关源码；模型包及交换能力后续预留 |
| `database/` | 数据库初始化、迁移、基础数据和运维脚本 |
| `tests/` | 单元、契约、集成和验收测试 |
| `deploy/` | 本地、测试和生产环境部署配置 |
| `tools/` | 模型校验、导入导出和开发辅助工具 |

当前已有前端模板和 Java 后端基础工程。需求基线为 SRS-OM-001 v1.7.0（Approved），技术设计以唯一 TDD-OM-002 v1.2.4（Draft）为事实源（TDD-OM-001 主稿文件已不存在，其结论已被 TDD-OM-002 吸收）。本轮聚焦对象可编辑图、右侧属性/关系配置、对象内领域选择/新增、布局恢复及完整 JSON；领域清单只展示、领域 API 完整实现（TDD-OM-002 DEV-1），规则/术语原设计保留。ADR-OM-001/002 v0.5.0 仍 Proposed，ADR-OM-003 暂缓；领域专门管理及检查/报告/核查暂缓，需求仍保留。首期持久化为本地 JSON 文件（TDD-OM-002 §10，用户确认），数据库相关依赖为目标态、MVP 不激活。业务实现按设计批准和实施计划推进；文档更新不等于已有业务页面或迁移。

## 追溯约定

- 需求和验收条件的事实源是 `曦元本体平台SDD开发/`。
- 测试名称可以引用 `AC-*`，但需求状态不由测试文件直接修改。
- 数据库迁移、模型包和构建版本随任务、变更申请和发布记录追溯。
- 构建目录、临时导出包、密钥和环境专属配置不提交到源码目录。
